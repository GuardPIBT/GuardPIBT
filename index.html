Overview

Learning global traffic while keeping PIBT in control.

City-scale UAV fleets require three-dimensional coordination beyond repeated joint-state search. PIBT is efficient online, but its one-step distance ordering is myopic when remote populations converge on the same bottleneck. the proposed method augments the executor with a guarded neural residual: message-aware graph attention models nearby interactions, while fixed-grid rectified-flow tokens summarize global source-to-goal transport.

The fused representation scores PIBT's 27 native 3D candidates. A regret bound and an execution-aligned counterfactual gate restrict intervention, so priority inheritance, claims, backtracking, and anti-swap checks remain responsible for every final action.

Method

Global context, local decisions, discrete guarantees.

The learned module changes candidate order only. PIBT still resolves the joint action.

01

Rectified-flow transport tokens

Fixed-grid tokens model long-range source-to-goal traffic with global self-attention and flow-matching supervision.

02

Two-stage cross-attention

Local GAT features read the global flow field, then fused agent features attend to PIBT's 27 candidate actions.

03

Executor-aligned intervention

Counterfactual rollout labels, bounded regret, adaptive grouping, and selective repair keep learning tied to executable outcomes.
